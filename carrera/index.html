HTML

Para crear un título

<h1> → título principal

Para crear un subtítulo

<h2> → subtítulo

Para crear un párrafo

<p> → crea un párrafo

Para crear un enlace

<a> → crea un enlace

Para indicar dónde lleva un enlace

href → indica el destino del enlace

CSS

Para cambiar el color del texto

color → cambia el color del texto

Para cambiar el fondo

background-color → cambia el color del fondo

Para crear espacio interno

padding → espacio dentro del elemento

Para crear un borde

border → crea un borde

Para redondear esquinas

border-radius → redondea las esquinas

Para crear espacio externo

margin → espacio fuera del elemento

Para cambiar el ancho

width → cambia el ancho

Para alinear texto

text-align → alinea el texto

Para quitar el subrayado

text-decoration → controla la decoración del texto

Para hacer cambios suaves

transition → suaviza los cambios visuales

Para cuando pasás el mouse

:hover → aplica estilos cuando el mouse está encima
